# 车载usb 云端产品化 PRD（面向 To C）

## 1. 背景与目标
- **目标用户**：在中国境内的电车车主，使用树莓派等 SBC 运行 Teslausb 作为车载 USB 存储。
- **产品目标**：在车辆录制哨兵模式/行车视频后，自动上传到云端，并在移动/桌面客户端为用户提供实时/历史观看能力。
- **商业模式**：SaaS 订阅（按存储容量、保留天数和并发实时流额度分级）。

## 2. 核心功能范围
1) **云端自动上传与推送**
   - Pi 端检测到新的哨兵模式文件后，自动上传到阿里云 OSS。
   - 上传完成后，通过消息通道（如 MQTT/FCM/阿里云移动推送）向客户端推送可用通知。
2) **历史视频存储与回看**
   - 所有上传的录像按车辆、日期、时间、摄像头视角分类存储。
   - 客户端支持按时间轴、事件类型（哨兵/行车）筛选并播放。
   - 提供下载与分享（受权限控制，可设置有效期/单次链接）。
3) **实时查看车辆周围**
   - 客户端可发起实时查看请求；
   - Pi 端在车端网络rclone模式下如何实现接近实时地视频显示。

## 3. 角色与使用场景
- **车主（终端用户）**：绑定车辆，查看推送通知，播放历史/实时视频。
- **运维/客服**：处理账号问题、查看设备在线状态、监控上传/推流健康。

## 4. 产品流程概览
1. Pi 端侦测到哨兵模式新文件 → 通过 OSS SDK 上传到指定 Bucket（按路径规则存储）。
2. 上传成功 → 写入元数据（例如存 MongoDB 或 MySQL）并发消息到消息队列/推送服务。
3. 客户端收到推送 → 拉取播放地址（OSS 私有 URL + 临时访问凭证/STS 签名）。
4. 客户端回看历史 → 调用后台 API 获取文件列表与播放/下载 URL。
5. 客户端请求实时查看 → 后台下发指令到 Pi（MQTT/WebSocket），Pi 启动近实时推流 → 客户端播放。

## 5. 功能需求（细化）
### 5.1 设备绑定与认证
- 支持账号体系（手机号 + 短信验证码登录；可选微信登录）。
- 设备与账户绑定（扫码或输入设备 ID），同一账号可绑定多辆车。
- 设备状态上报：在线/离线、存储剩余空间、最近同步时间。

### 5.2 上传与存储
- 路径规范：`/videos/{vin}/{date}/{time}/{camera}.mp4`，日期格式 `YYYY-MM-DD`，时间 `HH-mm-ss`。
- 元数据字段：VIN、设备 ID、上传时间、文件大小、时长、摄像头类型（front/rear/left/right）、事件类型（sentry/drive）、哈希校验值。
- 失败重传：Pi 端断网/掉电后续传；后台对账定期校验缺失文件。
- 分层存储策略：近 30 天热存储，超过 30 天可迁移冷存（OSS IA/Archive），遵循套餐策略。

### 5.3 推送与通知
- 上传成功推送：含缩略图（可在 Pi 端或云函数生成）、时长、时间。
- 异常告警推送：设备离线、云端配额不足。

### 5.4 历史回看
- 按日期、事件类型、摄像头筛选列表，支持模糊搜索。
- 支持拖动时间轴、倍速播放、画质选择（原画/压缩转码）。
- 下载与分享：生成带过期时间的临时签名 URL；可限制单次/多次访问。

### 5.5 实时查看
- 请求模型：客户端 → 后台 → MQTT/WebSocket 指令 → Pi 启动推流。
- 推流协议：优先 WebRTC（低延迟，需信令服务器 + STUN/TURN），备选低延迟 HLS。
- 安全控制：
  - 仅绑定账户可发起；
  - 一次请求有效期（例如 5 分钟）；
  - 带宽/并发限流；
  - 审计日志。

### 5.6 管理后台（最小需求）
- 设备列表与在线状态、上传成功率统计。
- OSS 存储用量与流量面板。
- 账号管理、套餐管理（存储配额、保留天数、实时流额度）。

### 5.7 客户端需求
- **平台**：微信小程序。
- **主要页面**：登录/注册、车辆列表、事件通知、历史时间轴、实时查看、设置（网络、存储、隐私）。
- **播放体验**：断点续播、后台播放、弱网自适应码率、横竖屏切换、截图/关键帧保存。

## 6. 阿里云 OSS 与云端设计
- **Bucket 规划**：按地域选择低时延区域；开启版本控制与生命周期规则（30/90 天归档）。
- **访问控制**：Bucket 设为私有；服务端使用 RAM 角色/STS 临时凭证签发给客户端，签名 URL 有效期短（如 10 分钟）。
- **上传方式**：
  - Pi 端：直传 OSS（多段上传，断点续传）；
  - 缩略图与转码：可用 OSS 触发函数计算（FC）或媒体处理 MPS。
- **加速与带宽**：启用 CDN 加速域名，HTTPS 强制；地域跨区时使用传输加速。
- **数据安全**：服务端持久化哈希校验，定期校验文件完整性；开启 OSS 服务端加密（SSE-KMS）。

## 7. 后端接口（示例草案）
- `POST /api/v1/auth/login`：手机号验证码登录。
- `POST /api/v1/devices/{device_id}/bind`：绑定设备。
- `GET /api/v1/videos`：查询历史文件，支持过滤参数（vin/date/type/camera）。
- `POST /api/v1/videos/{id}/share`：生成临时分享链接。
- `POST /api/v1/live/start`：发起实时查看请求（包含 VIN、摄像头/视角、分辨率）。
- `GET /api/v1/live/{session_id}`：获取实时流播放信息（WebRTC SDP/LL-HLS URL）。
- `POST /api/v1/webhook/oss`：OSS 事件回调（上传完成/转码完成）。

## 8. 客户端与 SDK 对接要点
- 内置 OSS 签名 URL 播放与断点续传下载；支持自定义 User-Agent 便于统计。
- 推送通道：国内使用厂商通道/阿里云移动推送；海外可切换 FCM。
- 实时查看需集成 播放能力（使用现成 SDK），并支持 TURN 认证。
- 日志收集：播放器错误、启动耗时、平均码率、丢包率。

## 9. 非功能与合规
- SLA 目标：99.9% 云端可用性；客户端冷启动 < 3s；视频首帧 < 2s（实时流除外）。
- 隐私与合规：车辆视频属个人敏感信息，需征得用户授权；提供删除账号与数据导出；日志脱敏；符合中国个人信息保护要求。
- 安全：接口鉴权（JWT + HTTPS）、防重放、频率限制、越权检测；重要操作审计。

## 10. 里程碑与交付
- **MVP（4-6 周）**：上传/存储、通知、历史回看（原画），基础账号与设备绑定，简单管理后台。
- **迭代 2**：实时查看、转码与多码率、缩略图、分享链接、CDN 加速。
- **迭代 3**：套餐计费、运营统计、客服工具、第三方 Webhook。

## 11. 验收标准（MVP）
- 设备上传成功率 ≥ 95%，失败可自动重传。
- 客户端能在上传后 1 分钟内收到推送并正常播放。
- 历史列表加载 < 2s；播放成功率 ≥ 99%。
- 实时查看在可用网络下延迟 ≤ 3s，失败有明确错误提示。

## 12. 交付物
- 后端：API 文档（OpenAPI）、部署脚本（IaC）、监控与日志方案。
- 客户端：原型与 UI 设计、小程序 应用、播放 SDK 集成、崩溃/日志上报。
- 运维：运维手册、应急预案、排障指南、SLA 监控仪表板。
